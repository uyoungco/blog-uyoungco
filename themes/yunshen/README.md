# 云深处 · Hexo 主题

宣纸为底，黛墨为字，朱砂点睛，泥金勾线。参考[橘猫小窝](https://jumaomaomaoju.cn/)及其[设计规范](https://github.com/IwannaYuJie/web/blob/main/docs/DESIGN_GUIDE.md)，使用 EJS、原生 CSS 与 JavaScript 独立实现，水墨远山为原创 SVG。

适用于 Hexo 8；当前项目已经安装所需的 EJS、Markdown 渲染器，无需增加运行依赖。

## 使用

本项目已启用主题。移植到其他 Hexo 项目时，将整个 `yunshen` 目录复制到 `themes/`，并在站点根目录 `_config.yml` 设置：

```yaml
theme: yunshen
language: zh-CN
timezone: Asia/Shanghai
```

通过 `npm run build` 生成静态文件到 `public/`。本地预览可在获得启动服务授权后执行 `npm run server`。不依赖动态后端，无需部署原参考站的 React/管理系统。

发布前，请在站点 `_config.yml` 中设置真实的 `title`、`author`、`description`、`url`。如果部署在子目录，将 `url` 设置为包含子目录的完整地址，主题资源和搜索文章链接使用 Hexo 的 `url_for` 生成。

## 配置

主题默认配置在 `themes/yunshen/_config.yml`。建议在站点根目录新建 `_config.yunshen.yml` 覆盖设置，方便后续更新主题。例如：

```yaml
brand:
  seal: 山居
  note: 一隅小筑
hero:
  title: 山居记
  lines: [行到水穷处，, 坐看云起时。]
  description: 这里写下你的博客简介。
author:
  initial: 山
  bio: 这里写下你的个人介绍。
social:
  github: https://github.com/your-name
  email: you@example.com
footer:
  since: 2026
  icp: ''
  psb: ''
  psb_url: ''
```

首页主视觉标题适合 2–4 个汉字；较长的站点名称可保留在站点 `title` 中。`brand.seal`、`hero.seal` 适合两个字，作者头像字 `author.initial` 适合一个字。

导航通过 `menu` 数组配置，每项包含 `name`（雅称）、`plain`（白话）和 `path`（站内路径）。若修改站点的 `tag_dir`、`category_dir` 或 `archive_dir`，请同步修改导航对应路径。

页脚备案通过 `footer.icp`、`footer.psb` 分别填写完整的 ICP 与公安备案号，留空时隐藏对应项。ICP 固定链接至工信部备案网站；`footer.psb_url` 填写公安备案查询详情的完整地址。公安备案前显示随主题提供的本地图标，两条链接均在新标签页打开。备案信息默认横排、不加下划线，空间不足时自动换行。

## 写作

```yaml
---
title: 一篇文章的标题
date: 2026-11-11 10:00:00
categories: 技术札记
tags: [Hexo, 前端]
description: 用一两句话说明文章内容，将作为列表摘要与页面描述。
featured: true
---
```

- 首页「今日开卷」展示最新文章；「案头清供」优先展示最多 3 篇 `featured: true` 的文章，没有精选标记时展示其他近期文章。
- 阅读时长按每分钟约 400 个非空白字符估算，最少 1 分钟。
- 文章目录根据 Markdown 标题自动生成，代码块支持复制。
- 内容页使用 Noto Serif SC 可变字体：桌面主标题最大 50px / 900 字重，正文 18px / 2 行高；760px 以下正文为 17px / 1.95 行高。表格使用 Noto Sans SC，引用与元信息使用 ZCOOL XiaoWei。
- 正文支持泥金加粗底线、朱砂链接下划线、三线表、横向滚动与列对齐、朱砂渐变引用框、祥云二级标题、菱形三级标题及列表、中文有序列表、首字下沉和卷末落款。
- 文章页提供阅读进度、当前章节目录、复制文章链接与同分类相关阅读；1100px 以下隐藏侧栏目录，正文保持单栏。
- 正文图片可点击或用键盘打开放大查看器，支持适屏、缩放、拖动及同篇切图；桌面滚轮围绕指针缩放，手机支持双指缩放。左右方向键切图，`Esc`、关闭按钮或遮罩退出，并还原阅读位置与焦点。图片已有链接时保留原跳转；图注依次取 `figcaption`、`title`、`alt`。查看器沿用主题明暗配色，无需额外依赖或修改 Markdown。
- 摘要优先使用 `description`，其次使用 `<!-- more -->` 前的内容，最后截取正文。
- 首页与列表分页使用 Hexo 自带分页配置；在根目录调整 `index_generator.per_page` 和 `per_page`。

当前站点已使用迁入的博客文章替换主题示例，内容位于 `source/_posts/`；来源与迁移说明见根目录 README。

## 页面与交互

- 首页、文章页、按年/月归档、分类列表及详情、标签列表及详情、普通 Markdown 页面、关于页与 `404.html`。
- 标签总览、分类总览、默认关于页及 404 自动生成；已有同路径 Markdown 页面时优先保留用户页面。自定义关于页可创建 `source/about/index.md`，使用 `layout: page`。
- 原生搜索弹窗：点击放大镜或按 `/`、`Ctrl/⌘ + K` 打开，`Esc` 关闭。按需加载 `search.json`，支持标题、分类、标签和全文的多词匹配；索引包含所有已发布文章的正文，不含草稿。
- 页头主题按钮提供「跟随设备、浅色、深色」三个选项，默认跟随设备。手动偏好以 `yunshen-theme` 保存于本地，跨页面和标签页同步；存储不可用时仅在本页生效。刷新前恢复偏好，避免先亮后暗。
- 全站页头复用同一套山水、飞鸟与日月：其他页面背景高约 420px、手机 280px，向下渐隐并随滚动离开视口；日月缩为 132px / 88px，并降低透明度，正文布局和文章纸面保持原有样式。
- 日月独立于明暗主题：按访客当地时间 06:00–18:00 显示太阳，其他时间显示月亮，正午/午夜最高。夜间浅色仍显示柔和月亮，白天深色仍显示低亮度太阳。
- 月相使用浏览器内置中国农历，按大小月及连续月龄近似绘制盈亏；月轮尺寸在 72%–100% 之间变化。此为日历驱动的装饰效果，并非根据经纬度计算的真实天体位置。农历不可用时显示完整月轮；日月每分钟更新，页面后台暂停，返回时校准。
- 字体与初次排版就绪后，首页山水、题字、文字和内容区在约 1 秒内缓动出现；切换主题只过渡颜色，切回标签页或历史恢复不重播。尊重减少动态效果设置，760px 以下使用移动导航与横排标题。
- 入场结束后，三只飞鸟分别以 12 / 15 / 18 秒周期轻微浮动，水平不超过 3px、垂直不超过 2px；日月以 20 秒周期上下浮动不超过 2px、明暗变化约 4%。背景离开视口或标签页进入后台时暂停，返回后继续原有进度；开启减少动态效果时保持静态。
- 搜索需要 HTTP(S) 访问；直接双击 `public/index.html` 会受到浏览器的本地文件限制。代码复制需要 HTTPS 或 localhost。
- 404 状态与回退规则由静态托管服务配置；主题只负责生成 `404.html`。

## 字体与资源

全站采用均衡放大的阅读字号：基础文字 16px，摘要桌面 16px / 手机 15px，日期、标签等辅助信息桌面 14px / 手机至少 13px；导航主文字 18px，搜索输入框 16px。调整的字号使用 `rem`，浏览器默认字体大小和缩放设置可以继续生效。浅色辅助文字与金色文字分别加深，深色辅助文字提亮，装饰线和山水保留原有配色。

页头内容高度保持桌面 72px / 手机 64px；桌面导航副标题只在悬停或键盘聚焦时显示，手机展开菜单保持显示。手机最新文章卡片将日期横排于顶部，统计区分为四个等宽格，480px 以下侧栏使用单列；窄屏标签总览允许计数换行，380px 以下使用单列。卡片随文字自然增高，表格与代码在各自容器内横向滚动。

毛笔字使用 Ma Shan Zheng，导航及元信息使用 ZCOOL XiaoWei，内容正文与表格分别使用 Noto Serif SC、Noto Sans SC。均按 SIL Open Font License 1.1 分发，许可证位于 `source/fonts/`。字体使用 WOFF2 和 Unicode 分片，保留完整字形覆盖，浏览器只下载当前内容需要的分片。毛笔字与雅体的主题常用字包提前加载，避免每次下载两套完整字体；Noto 字体保留官方可变字重，内容页优先请求常用宋体分片。字体采用短暂阻塞文字绘制的策略，减少系统字体切换为主题字体时的闪变；首页入场动画在字体就绪后启动。另附 Noto Serif SC 的「回」字子集，修正 ZCOOL 的特殊字形。字体本地加载，无 Google Fonts/CDN 请求；未覆盖字形使用系统字体回退。字体来源为 [Google Fonts 开源仓库](https://github.com/google/fonts)。

首次显示前会等待本页字体与初次排版就绪，最多额外等待 2.5 秒；超时后未就绪的字体在本次访问中保持系统回退，避免晚到的字体再次改变文字与山水位置。再次访问可直接复用浏览器字体缓存；禁用 JavaScript 时页面仍可正常阅读。

主题没有外部脚本、跟踪器或在线图片依赖。山水 SVG、纹理和图标随主题提供。
